Know your data, then follow the six-phase lifecycle.

Theory

Sources & classification of data

Data comes from sensors, apps, logs, social media and transactions. Structured = tables (SQL). Semi-structured = JSON/XML with tags. Unstructured = text, images, video.

Characteristics & Big Data platform

The Vs: Volume, Velocity, Variety, Veracity, Value. Big Data platforms (Hadoop, Spark) spread storage and processing across many machines.

Analysis vs reporting

Reporting says what happened; analysis explains why and predicts what next.

Analytic process, tools & applications

Tools: R, Python, Excel, Tableau, Power BI, Spark. Used in healthcare, banking, retail, sports, smart cities.

Unit II · Data Analysis

From regression to neural networks and fuzzy logic.

Theory

Regression modeling

Fits a line y = a + bx that minimises squared error (least squares). R² tells how much variation the line explains.

Multivariate & Bayesian modeling

Multivariate: many variables at once. Bayes: P(H|D) = P(D|H)·P(H) / P(D). Bayesian networks draw these dependencies as a graph.

SVM & kernel methods

Find the widest-margin boundary between classes; kernels lift data into higher dimensions.

Time series

Data ordered in time: trend, seasonality, noise. Linear systems and nonlinear dynamics model it.

Neural networks & PCA

Learning = adjusting weights; generalisation = working on unseen data. PCA reduces dimensions by keeping directions of maximum variance.

Fuzzy logic

Truth is a degree from 0 to 1, e.g. “warm” = 0.7. Fuzzy decision trees use these degrees.

Also covered: rule induction, competitive learning, stochastic search methods.

Unit III · Mining Data Streams

Data that never stops: you see each item once.

Theory

Stream model & architecture

Items arrive continuously; memory is small, so we keep summaries, not everything.

Sampling & filtering

Sample by hashing a key. Filter with a Bloom filter: fast membership test, no false negatives.

Counting distinct elements & moments

Flajolet–Martin estimates distinct count using trailing zeros of hashes. AMS estimates the second moment.

Windows: counting ones & decay

DGIM counts 1s in the last N bits. A decaying window weights recent items more.

RTAP & case studies

Real-time sentiment analysis of tweets; stock price prediction from live ticks.

Unit IV · Frequent Itemsets & Clustering

Find what goes together and what groups together.

Theory

Market-basket & Apriori

Support = how often an itemset appears. Apriori rule: if an itemset is frequent, all its subsets are frequent, so we prune the rest.

Large data sets & streams

PCY, limited-pass and sampling algorithms handle data that does not fit in memory.

Hierarchical & K-means

Hierarchical merges nearest clusters step by step. K-means: assign points to the nearest centroid, move centroids, repeat.

High-dimensional clustering

CLIQUE (grid-based) and ProCLUS (projected clusters) work in subspaces.

Also covered: frequent-pattern clustering, non-Euclidean space, clustering for streams and parallelism.

Unit V · Frameworks, Visualization & R

Tools that run analytics at scale, and show the result.

Theory

MapReduce & Hadoop

Map emits (key, value) pairs; shuffle groups by key; reduce combines. HDFS stores big files in replicated blocks.

Pig, Hive, HBase, MapR

Pig: scripting. Hive: SQL-like queries. HBase: column store on HDFS. MapR: Hadoop distribution.

NoSQL, sharding & S3

NoSQL (document, key-value, column, graph) scales out. Sharding splits data across servers. S3 is object storage.

Visualization techniques

Choose the chart for the question: trend → line, compare → bar, relation → scatter, distribution → histogram.

Introduction to R

R GUIs (RStudio), data import/export, data types, descriptive statistics, EDA, visualise before you analyse, analytics for unstructured data.
